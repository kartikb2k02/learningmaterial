# The Growth Model

The arithmetic that turns a set of opinions into something that can be wrong. Six lessons on
writing your business as one equation, choosing the handful of inputs that actually feed it,
building it so that somebody else can argue with it, understanding what a forecast can honestly
promise, finding which input is worth a quarter of the team, and using the whole thing to refuse
work that cannot succeed.

| # | Lesson | The question it answers |
|---|---|---|
| 01 | [Your Business as One Equation](01-your-business-as-one-equation.md) | What is the single arithmetic statement your growth depends on, and who owns each term? |
| 02 | [Finding the Input Metrics](02-finding-the-input-metrics.md) | Which handful of numbers actually feed the output, and how do you tell them from the rest? |
| 03 | [Building the Model](03-building-the-model.md) | How do you build it so somebody else can argue with it, and find which assumption was wrong? |
| 04 | [What a Forecast Can and Cannot Promise](04-what-a-forecast-can-promise.md) | Where does the model stop being honest, and what is a single number actually worth? |
| 05 | [Sensitivity](05-sensitivity.md) | Which input moves the output, and which only feels important? |
| 06 | [Using the Model to Say No](06-using-the-model-to-say-no.md) | How does the model refuse an impossible target without anybody losing an argument? |

Every lesson in this topic uses the same seven term model, so the programs build on each other.
Lesson 01 sets it up and the rest interrogate it.
