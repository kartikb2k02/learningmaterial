# AI in Growth

What a model genuinely changes about this job, which is less than the enthusiasm suggests and more
than the scepticism does. Production gets much cheaper, measurement a little, decisions not at all,
and the work piles up at five constraints that were always there. These seven lessons work through
each of them with the arithmetic attached.
