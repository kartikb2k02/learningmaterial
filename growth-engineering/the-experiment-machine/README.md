# The Experiment Machine

The machinery that turns ideas into evidence, and the specific ways it lies when a part is
missing. What a platform is made of, why a rollout is not an experiment, where the silent
assignment bugs live, what peeking really costs, why the count of tests beats the quality of the
ideas, what a scoring framework is actually for, and how to write a result the organisation
believes.
